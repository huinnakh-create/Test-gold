# Gold Fair Value Intelligence

لوحة Streamlit لتقدير القيمة العادلة للذهب باستخدام بيانات شهرية من FRED.

## تشغيل محلياً
1. ثبّت Python.
2. افتح الطرفية داخل مجلد المشروع.
3. نفّذ:
   pip install -r requirements.txt
   streamlit run app.py
4. أدخل مفتاح FRED API في الشريط الجانبي.

## النشر مجاناً على Streamlit Community Cloud
1. أنشئ حساب GitHub وارفع ملفات هذا المشروع إلى مستودع جديد.
2. افتح https://share.streamlit.io/
3. اختر المستودع والفرع وملف `app.py`.
4. اضغط Deploy.
5. بعد النشر افتح إعدادات التطبيق ثم Secrets وأضف:
   FRED_API_KEY = "ضع_مفتاحك_هنا"
6. لتفعيل استخدام المفتاح من Secrets بدلاً من إدخاله يدوياً، يمكن لاحقاً تعديل التطبيق لقراءة `st.secrets`.

## الحصول على مفتاح FRED
https://fred.stlouisfed.org/docs/api/api_key.html

## حدود النموذج
- تقدير اقتصادي إحصائي وليس قيمة جوهرية يقينية.
- الذهب من سلسلة LBMA PM عبر FRED وقد تكون هناك فجوة زمنية في آخر قراءة.
- DTWEXBGS مؤشر الدولار التجاري الواسع، وليس DXY.
- لا يشمل بعد مشتريات البنوك المركزية وتدفقات ETF والإنتاج وإعادة التدوير.
- يجب اختبار النموذج خارج العينة ومراجعة جودة البيانات قبل استخدامه في قرارات مالية.
